# CollabUtils2

CollabUtils2 port for the Shared runtime. Workspace location: `Mods/CollabUtils2/`.

Projects:

- `Celeste.Mods.CollabUtils2.csproj`

Repository dependencies: **Shared, TAS**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/CollabUtils2/Celeste.Mods.CollabUtils2.csproj -c Release
```
